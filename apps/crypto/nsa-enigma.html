Rejewski attack lab — recover the day key from intercepts

A faithful rebuild of rejewski.py and the two NSA notebooks. Marian Rejewski’s 1932 attack reconstructs the AD/BE/CF permutations from double-enciphered message keys, reads off their cycle-length signature, and looks that signature up in a catalogue of all 26³ × 6 = 105,456 settings. The cycle structure survives the plugboard (AD = Q ˆ​T ˆ​Q is a conjugate — cycle lengths are invariant), so the catalogue is built plug-free while the traffic is plugged. The NSA suite shipped this as a pickled dictionary; here the catalogue is computed on demand in your browser.

How to break Enigma like Rejewski (condensed from BreakingEnigma.ipynb / MasterEnigmaCracker.ipynb)

The scenario (notebook markdown, verbatim in spirit)

“It’s midnight at Bletchley, the middle of your nighttime shift. The past days of German army traffic you decrypted have hinted at some major events to come today. Since the new day began at midnight, the Germans have changed their day key. If you can’t find the new settings, all of that traffic will be gibberish…”

Step 1 — know the machine

Each keypress: step rotors, run the letter through the plugboard, rotors L→M→R, reflector, then back R→M→L and through the plugboard again. The reflector makes the machine an involution: encipher = decipher, and no letter can ever encipher to itself. Operators encrypted each message key twice at the day key (six-letter indicator ABCDEF with D=E+F= the key repeated) — the fatal procedural habit.

Step 2 — build the AD/BE/CF permutations from the indicators

For a six-letter indicator c₁c₂c₃c₄c₅c₆: positions 1&4 encode the same key letter (permutations P₁ and P₄), likewise 2&5 and 3&6. Collect over many indicators: AD = P₄∘P₁, BE = P₅∘P₂, CF = P₆∘P₃. Because the plugboard enters as Q ˆ​Pᵢ ˆ​Q on both ends, AD = Q ˆ​(P₄∘P₁) ˆ​Q — a conjugate, so its cycle-length structure is unchanged by unknown plugs.

Step 3 — cycles and the chain index

Write each permutation in cycle notation. The notebook example (true data):

Sorted cycle lengths give the index AD:222299 BE:11221010 CF:6677. Note the NSA notebook’s own lookup cell hard-codes a different, stale string — covered in Findings.

Step 4 — the catalogue: 105,456 settings → 2 candidates

For every day key (26³) and every rotor order (6 permutations of I/II/III — the NSA simulator offers no rotor IV), compute the chain index and keep the matches. For the notebook data the survivors are exactly:

YAQ / II-I-III ← the true secret day key AAC / II-III-I ← a coincidence (decoy)

The NSA suite ships this catalogue as a pickle. Here it is recomputed from scratch, in your browser, in seconds.

Step 5 — recover the plugboard, then read the traffic

The catalogue pins rotors+windows but not the plugs. The notebooks let the student guess swaps and test-decrypt (test_putative_key). This lab does it with arithmetic instead: with the setting known, each plug pair must satisfy AD(u) = Q(T(Q(u))) with T known — beam-search pairs by agreement count (78 exact constraints), then confirm by decrypting the three intercepted messages and scoring them as English. Expect the plugboard JS HY NF and three familiar quotations from Einstein, Hemingway and Roosevelt.

Deep-dive findings // “no filter”

Everything below was established by executing the NSA sources (CPython 3) against published reference vectors, and re-proven here in the browser port. Full org survey: docs/nsa-github-deep-dive.md.

ENG-1 · simulation fidelity
The NSA “Enigma” is not a historical Enigma. machine.py steps the left rotor on every keypress and cascades rightward (l.rotor.step() in encode_decode_letter), where the real machine steps the right rotor and cascades leftward with the double-step anomaly. On the canonical vector (rotors I-II-III, reflector B, key AAA, no plugs) the NSA simulator emits FTZMG where every real Enigma I emits BDZGO. It also lacks Ringstellung entirely, ships no rotor IV, and hard-wires reflector B. The attack still works on it because the attack only needs a deterministic involution machine — but traffic produced by the NSA simulator is not historically valid ciphertext. Both engines are provided here; the divergence is a self-test.
ENG-2 · notebook integrity
The walkthrough notebooks contain stale, mutually inconsistent data. MasterEnigmaCracker cell 22 looks up chains_dict['AD:6677 BE:11221010 CF:221111'], but the index recomputed from the cycles the same notebook prints (cells 17–19) is AD:222299 BE:11221010 CF:6677. Both strings resolve to the same candidate pair in the (unshipped) pickle — evidence the intercept data changed between notebook runs and the printed outputs were never refreshed. The markdown “recall that these are of the form…” cycle strings differ from the printed code output in both notebooks.
ENG-3 · missing artifacts
The lesson’s two data files are not in the repository: message_key_encrypts.pickle and chains.pickle are load()ed but were never committed, so the notebooks cannot run as shipped. 23 intercepts and the full AD/BE/CF cycles survive only as printed outputs. This port regenerates an equivalent scenario deterministically (seeded PRNG, same secret) and rebuilds the catalogue on demand instead of pickling 105,456 entries.
ENG-4 · code quality (kept faithfully)
rejewski.py: if i is 1 / is 2 compare integers by identity (works on CPython small-int caching, not portable); alphabet.replace(next_letter, '') discards its result (no-op); the AD/BE/CF maps are filled by encrypting random keys until complete (~hundreds of enciphers; this port uses an exact sweep or direct permutation composition). components.py: the 6-plug cap only rejects a single update listing >6 pairs — cumulative updates can exceed 6. All of it is preserved where harmless and documented where not.
ENG-5 · the maths is sound and lovely
The chain-index attack rests on a genuinely elegant fact: enciphering under plugs is Q ˆ​P ˆ​Q, so AD = Q ˆ​(P₄∘P₁) ˆ​Q — a conjugation, and conjugate permutations have identical cycle structure. Verified end-to-end here: plugged intercepts match the plug-free catalogue (self-test §9), and the catalogue really does reduce 105,456 settings to the true day key plus one decoy.
ENG-6 · performance
The reference workflow (build the full chains dictionary in CPython) took ~25 minutes of compute in this sandbox; the same search as composed permutations in JS runs in ~4 s in a browser, single-threaded, with the fast path asserted equal to the literal encipher-based path (self-test §14).
ENG-7 · scope of the source suite
The NSA org has no HTML5 repo at all (89 repositories; only their site listing is HTML). The closest “suite of utilities” that converts cleanly to a browser artifact is this Enigma teaching suite — which is what this file is. Runner-up: the GPL-2 QGIS coordinate-tool plugin family (MGRS/UTM/GEOREF/plus-codes converters) — convertible, but heavier licensing and largely QGIS-bound. Survey and triage: docs/nsa-github-deep-dive.md.
