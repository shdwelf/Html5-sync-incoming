🔁 Quine — Self-Replicating Image Formats

A quine is a program that outputs its own source code without reading any file. Named after philosopher Willard Van Orman Quine. Kleene's recursion theorem (1938) proves any computable function can access its own description — making quines always possible.

Here, we encode the quine encoder's source code into image formats. The resulting image file contains its own generator as pixel data. Decode the pixels back to ASCII and you recover the exact source code that created them.

🧠 The Quine Trick: Two-Part Structure
PART 1 (DATA):     Contains the source code encoded as bytes
PART 2 (INTERPRETER): Reads PART 1 and outputs the full program

The key insight: DATA encodes BOTH parts.
INTERPRETER reads DATA → outputs DATA + INTERPRETER → complete source
No infinite regress! This is Kleene's fixed-point theorem in action.

📚 Quine Theory & History

Kleene's Recursion Theorem (1938)

Stephen Kleene proved that for any total computable function f, there exists a program e such thatφ_e = φ_{f(e)} — the program behaves as if it "knows its own source code."This is the mathematical foundation for quines and self-replicating programs.

The Two-Part Quine Pattern
data = "source code as string"
code = "print(data); print(data)"
// data encodes both data AND code
// code reads data and outputs both
// No file I/O needed!
Famous Quines
  • • Quine–McCluskey algorithm (1956) — Boolean minimization
  • • Ken Thompson's "Reflections on Trusting Trust" (1984) — compiler Trojan quine
  • • Smallest C quine — 78 chars with printf self-reference
  • • Quine relay (128 languages) — Ueda Hiroki's 2013 masterpiece
Image Format Quines

An image format quine encodes the encoder source code as pixel data. BMP: 1 char per pixel (BGR channels). PPM: ASCII values as grayscale. QOI: hash-based run-length encoding of source bytes. XPM: unique characters per color — the file IS valid C source AND an image. These demonstrate the polyglot nature of data: the same bytes can be code, image, text, and binary simultaneously.
