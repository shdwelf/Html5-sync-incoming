GEDCOM → HTML5 + Melissa Geocoding + TSP Planner

Final inline single-file HTML5 build: loads GEDCOM, converts genealogy/place data into an HTML5 report, geocodes places with Melissa Cloud or alternative lookups, then creates Traveling Salesman Problem route solutions with downloadable travel lists.

2) Melissa lookup settings

Melissa Cloud note: browser geocoding needs your Melissa License Key and may require CORS support or a small server/proxy. The app never embeds a key; enter it only when you want live lookups.
Melissa API resources used by this app

This app is wired for Melissa Cloud Global Address Verification, which can append latitude and longitude when an address/place is accepted.

  • MelissaData GitHub
  • Melissa Cloud API OpenAPI repo
  • Global Address OpenAPI page
  • Global Address docs

2b) Alternative geocoders

Research-backed alternatives: use Census for U.S./Puerto Rico addresses without a key; use key-based providers for higher volume or global lookups. Nominatim-compatible support is intended for a self-hosted or explicitly approved endpoint, not unattended bulk use of the public server.
Provider endpoint notes
  • Census: /geocoder/locations/onelineaddress?address=...&benchmark=Public_AR_Current&format=json
  • Geoapify: https://api.geoapify.com/v1/geocode/search?text=...&format=json&apiKey=KEY
  • Geocod.io: https://api.geocod.io/v1.7/geocode?q=...&api_key=KEY
  • OpenCage: https://api.opencagedata.com/geocode/v1/json?q=...&key=KEY
  • HERE: https://geocode.search.hereapi.com/v1/geocode?q=...&apiKey=KEY
  • Mapbox: https://api.mapbox.com/geocoding/v5/mapbox.places/{query}.json?access_token=TOKEN
  • LocationIQ: https://us1.locationiq.com/v1/search?key=KEY&q=...&format=json
  • MapTiler: https://api.maptiler.com/geocoding/{query}.json?key=KEY
  • MapQuest: https://www.mapquestapi.com/geocoding/v1/address?key=KEY&location=...
  • ArcGIS: /World/GeocodeServer/findAddressCandidates?singleLine=...&f=json&token=TOKEN
  • GeoNames: https://secure.geonames.org/searchJSON?q=...&maxRows=1&username=USERNAME
  • Wikidata: SPARQL lookup for entities with coordinate location P625
  • Pelias: /v1/search?text=...; Photon: /api?q=...
