# CRACKTRO // DEMOSCENE — an original homage

A single, self-contained HTML5 page that pays tribute to the home-computer
crack-intro & demoscene era (Commodore 64 and friends, 1982 onward) — as **history
and craft**. Every visual is drawn live on `<canvas>` with the classic C64 palette,
and the soundtrack is synthesised in-browser with **WebAudio** (an original SID-style
chiptune loop). No external files are loaded; it works fully offline.

## What's inside
- **Animated stage** — raster-bar + starfield backdrop, a bouncing logotype bar, and
  the classic edge-to-edge marquee scroller.
- **WebAudio chiptune** — 3-voice original loop (square lead, triangle bass, noise
  percussion). Toggle with the ♪ button (audio starts on user gesture).
- **A short history** of the crack-intro → demoscene evolution (general, accurate
  framing; not affiliated with any crew).
- **Style gallery** — six original "genre" cards (loader digits, raster bars,
  scrolltext, logo, plasma, credits) rendered live.

## Boundaries
This page celebrates the *craft* and history of the scene and distributes **no**
cracked software, keygens, or anyone's copied work. It is an educational homage with
freshly generated art and music. The genuine historical originals are preserved by
the Internet Archive (e.g. its C64 software-library cracktros collection) and scene
archives; this project points users there rather than reproducing their files.
